# [Group] _artemis organization workspace_

Manage Kore.ai Artemis workspaces.

## Commands

- [create](/Commands/artemis/organization/workspace/_create.md)
: Create a Workspace under an Organization (long-running).

- [delete](/Commands/artemis/organization/workspace/_delete.md)
: Delete a Workspace under an Organization (long-running).

- [link-saas](/Commands/artemis/organization/workspace/_link-saas.md)
: Links SaaS resources to the workspace. Accepts the full list of SaaS assets to be linked.

- [list](/Commands/artemis/organization/workspace/_list.md)
: List Workspaces under an Organization.

- [list-linked-saas](/Commands/artemis/organization/workspace/_list-linked-saas.md)
: Returns the list of SaaS resources linked to the workspace.

- [show](/Commands/artemis/organization/workspace/_show.md)
: Get a Workspace under an Organization.

- [show-details](/Commands/artemis/organization/workspace/_show-details.md)
: Show detailed workspace information, including projects.

- [update](/Commands/artemis/organization/workspace/_update.md)
: Update a Workspace under an Organization (long-running).
