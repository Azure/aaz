# [Group] _storage context-cache container_

Manage Context Cache containers.

## Commands

- [create](/Commands/storage/context-cache/container/_create.md)
: Create a container in a Context Cache.

- [delete](/Commands/storage/context-cache/container/_delete.md)
: Delete a container from a Context Cache.

- [list](/Commands/storage/context-cache/container/_list.md)
: List all containers in a Context Cache.

- [show](/Commands/storage/context-cache/container/_show.md)
: Get a container in a Context Cache.

- [update](/Commands/storage/context-cache/container/_update.md)
: Update a container in a Context Cache.
