# [Group] _networksecurity neuroshield finding_

Manage Finding

## Commands

- [list](/Commands/networksecurity/neuroshield/finding/_list.md)
: Lists findings under a protected resource.

- [mitigate](/Commands/networksecurity/neuroshield/finding/_mitigate.md)
: Triggers mitigation for all awaiting-approval mitigations under a finding.

- [rollback](/Commands/networksecurity/neuroshield/finding/_rollback.md)
: Rolls back succeeded rollbackable mitigations under a finding.

- [show](/Commands/networksecurity/neuroshield/finding/_show.md)
: Gets a finding under a protected resource.
