# [Group] _networksecurity neuroshield protected-resource_

Manage Protected Resource

## Commands

- [create](/Commands/networksecurity/neuroshield/protected-resource/_create.md)
: Creates or updates a protected resource under a NeuroShield resource.

- [delete](/Commands/networksecurity/neuroshield/protected-resource/_delete.md)
: Deletes a protected resource under a NeuroShield resource.

- [list](/Commands/networksecurity/neuroshield/protected-resource/_list.md)
: Lists all protected resources under a NeuroShield resource.

- [show](/Commands/networksecurity/neuroshield/protected-resource/_show.md)
: Gets a protected resource under a NeuroShield resource.

- [trigger-inventory-upload](/Commands/networksecurity/neuroshield/protected-resource/_trigger-inventory-upload.md)
: Requests a fresh inventory upload from the Neuron agents associated with a protected resource.
