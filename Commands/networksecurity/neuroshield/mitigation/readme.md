# [Group] _networksecurity neuroshield mitigation_

Manage Mitigation

## Commands

- [execute](/Commands/networksecurity/neuroshield/mitigation/_execute.md)
: Approves and queues a mitigation for execution.

- [list](/Commands/networksecurity/neuroshield/mitigation/_list.md)
: Lists mitigations under a protected resource.

- [rollback](/Commands/networksecurity/neuroshield/mitigation/_rollback.md)
: Rolls back a mitigation when rollback is available.

- [show](/Commands/networksecurity/neuroshield/mitigation/_show.md)
: Gets a mitigation under a protected resource.
