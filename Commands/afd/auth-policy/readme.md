# [Group] _afd auth-policy_

Manage authentication policies within an Azure Front Door profile.

## Commands

- [create](/Commands/afd/auth-policy/_create.md)
: Create an authorization policy within the specified profile.

- [delete](/Commands/afd/auth-policy/_delete.md)
: Delete an existing authorization policy within a profile.

- [list](/Commands/afd/auth-policy/_list.md)
: List authorization policies associated with the profile.

- [show](/Commands/afd/auth-policy/_show.md)
: Get an existing authorization policy within a profile.

- [update](/Commands/afd/auth-policy/_update.md)
: Update an authorization policy within the specified profile.
