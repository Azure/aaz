# [Group] _web site silo virtual-network-connection virtual-network_

Manage Virtual Network

## Commands

- [create](/Commands/web/site/silo/virtual-network-connection/virtual-network/_create.md)
: Create a virtual network connection to a silo, or updates the connection properties.

- [delete](/Commands/web/site/silo/virtual-network-connection/virtual-network/_delete.md)
: Delete the virtual network connection from a silo.

- [show](/Commands/web/site/silo/virtual-network-connection/virtual-network/_show.md)
: Get the virtual network the silo is connected to.

- [update](/Commands/web/site/silo/virtual-network-connection/virtual-network/_update.md)
: Update a virtual network connection to a silo, or updates the connection properties.
