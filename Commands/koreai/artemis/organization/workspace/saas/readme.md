# [Group] _koreai artemis organization workspace saas_

Manage SaaS marketplace resources linked to a Kore.ai Artemis workspace.

## Commands

- [link](/Commands/koreai/artemis/organization/workspace/saas/_link.md)
: Links SaaS resources to the workspace. Accepts the full list of SaaS assets to be linked.

- [list](/Commands/koreai/artemis/organization/workspace/saas/_list.md)
: Returns the list of SaaS resources linked to the workspace.
