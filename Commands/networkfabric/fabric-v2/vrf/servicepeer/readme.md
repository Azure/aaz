# [Group] _networkfabric fabric-v2 vrf servicepeer_

Manage Service Peer

## Commands

- [confirm-attachment](/Commands/networkfabric/fabric-v2/vrf/servicepeer/_confirm-attachment.md)
: Confirms a previously prepared service endpoint attachment.

- [create](/Commands/networkfabric/fabric-v2/vrf/servicepeer/_create.md)
: Create a ServicePeer.

- [delete](/Commands/networkfabric/fabric-v2/vrf/servicepeer/_delete.md)
: Delete the specified ServicePeer.

- [list](/Commands/networkfabric/fabric-v2/vrf/servicepeer/_list.md)
: List ServicePeers by Vrf.

- [prepare-attachment](/Commands/networkfabric/fabric-v2/vrf/servicepeer/_prepare-attachment.md)
: Prepares a single-consumer service endpoint attachment.

- [revoke](/Commands/networkfabric/fabric-v2/vrf/servicepeer/_revoke.md)
: Revokes an attachment and withdraws service exposure before cleanup.

- [show](/Commands/networkfabric/fabric-v2/vrf/servicepeer/_show.md)
: Get the specified ServicePeer.

- [update](/Commands/networkfabric/fabric-v2/vrf/servicepeer/_update.md)
: Update a ServicePeer.
