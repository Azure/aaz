# [Group] _commvault cloud-account storage_

Manage the storage of a cloud account.

## Commands

- [create](/Commands/commvault/cloud-account/storage/_create.md)
: Create a storage.

- [delete](/Commands/commvault/cloud-account/storage/_delete.md)
: Delete a storage.

- [disable-compliance-lock](/Commands/commvault/cloud-account/storage/_disable-compliance-lock.md)
: Request disabling the compliance lock on a storage (requires multi-person authorization approval).

- [enable-compliance-lock](/Commands/commvault/cloud-account/storage/_enable-compliance-lock.md)
: Enable the compliance lock on a storage.

- [list](/Commands/commvault/cloud-account/storage/_list.md)
: List the storages of a cloud account.

- [refresh](/Commands/commvault/cloud-account/storage/_refresh.md)
: Refresh the state of a storage from Commvault.

- [show](/Commands/commvault/cloud-account/storage/_show.md)
: Get a storage.

- [update](/Commands/commvault/cloud-account/storage/_update.md)
: Update a storage.
