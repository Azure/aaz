# [Group] _commvault cloud-account identity_

Manage the managed identities of a cloud account.

## Commands

- [assign](/Commands/commvault/cloud-account/identity/_assign.md)
: Assign managed identities to a cloud account.

- [remove](/Commands/commvault/cloud-account/identity/_remove.md)
: Remove managed identities from a cloud account.

- [show](/Commands/commvault/cloud-account/identity/_show.md)
: Show the managed identities of a cloud account.
