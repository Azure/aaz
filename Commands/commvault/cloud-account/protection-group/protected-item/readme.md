# [Group] _commvault cloud-account protection-group protected-item_

Manage the protected items of a protection group.

## Commands

- [get-restore-point](/Commands/commvault/cloud-account/protection-group/protected-item/_get-restore-point.md)
: Get the restore points of a protected item.

- [list](/Commands/commvault/cloud-account/protection-group/protected-item/_list.md)
: List the protected items of a protection group.

- [restore](/Commands/commvault/cloud-account/protection-group/protected-item/_restore.md)
: Restore a protected item.

- [show](/Commands/commvault/cloud-account/protection-group/protected-item/_show.md)
: Get a protected item.
