# [Group] _cloud-service update-domain_

Manage Update Domain

## Commands

- [list-update-domain](/Commands/cloud-service/update-domain/_list-update-domain.md)
: List a list of all update domains in a cloud service.

- [show-update-domain](/Commands/cloud-service/update-domain/_show-update-domain.md)
: Get the specified update domain of a cloud service. Use nextLink property in the response to get the next page of update domains. Do this till nextLink is null to fetch all the update domains.

- [walk-update-domain](/Commands/cloud-service/update-domain/_walk-update-domain.md)
: Updates the role instances in the specified update domain.
