# [Group] _cloud-service role-instance_

Manage Role Instance

## Commands

- [delete](/Commands/cloud-service/role-instance/_delete.md)
: Delete a role instance from a cloud service.

- [list](/Commands/cloud-service/role-instance/_list.md)
: List the list of all role instances in a cloud service. Use nextLink property in the response to get the next page of role instances. Do this till nextLink is null to fetch all the role instances.

- [rebuild](/Commands/cloud-service/role-instance/_rebuild.md)
: The Rebuild Role Instance asynchronous operation reinstalls the operating system on instances of web roles or worker roles and initializes the storage resources that are used by them. If you do not want to initialize storage resources, you can use Reimage Role Instance.

- [reimage](/Commands/cloud-service/role-instance/_reimage.md)
: The reimage role instance asynchronous operation reinstalls the operating system on instances of web roles or worker roles.

- [restart](/Commands/cloud-service/role-instance/_restart.md)
: The Reboot Role Instance asynchronous operation requests a reboot of a role instance in the cloud service.

- [show](/Commands/cloud-service/role-instance/_show.md)
: Get a role instance from a cloud service.

- [show-instance-view](/Commands/cloud-service/role-instance/_show-instance-view.md)
: Get information about the run-time state of a role instance in a cloud service.

- [show-remote-desktop-file](/Commands/cloud-service/role-instance/_show-remote-desktop-file.md)
: Get a remote desktop file for a role instance in a cloud service.
