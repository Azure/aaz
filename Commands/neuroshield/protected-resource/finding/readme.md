# [Group] _neuroshield protected-resource finding_

Manage Finding

## Commands

- [list](/Commands/neuroshield/protected-resource/finding/_list.md)
: List findings under a protected resource.

- [mitigate](/Commands/neuroshield/protected-resource/finding/_mitigate.md)
: Triggers mitigation for all awaiting-approval mitigations under a finding.

- [rollback](/Commands/neuroshield/protected-resource/finding/_rollback.md)
: Rolls back succeeded rollbackable mitigations under a finding.

- [show](/Commands/neuroshield/protected-resource/finding/_show.md)
: Get a finding under a protected resource.
