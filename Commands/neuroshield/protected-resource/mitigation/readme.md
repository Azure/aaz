# [Group] _neuroshield protected-resource mitigation_

Manage Mitigation

## Commands

- [execute](/Commands/neuroshield/protected-resource/mitigation/_execute.md)
: Approves and queues a mitigation for execution.

- [list](/Commands/neuroshield/protected-resource/mitigation/_list.md)
: List mitigations under a protected resource.

- [rollback](/Commands/neuroshield/protected-resource/mitigation/_rollback.md)
: Rolls back a mitigation when rollback is available.

- [show](/Commands/neuroshield/protected-resource/mitigation/_show.md)
: Get a mitigation under a protected resource.
