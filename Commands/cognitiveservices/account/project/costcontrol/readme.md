# [Group] _cognitiveservices account project costcontrol_

Manage Cost Control

## Commands

- [create](/Commands/cognitiveservices/account/project/costcontrol/_create.md)
: Create a project-owned budget synchronously.

- [delete](/Commands/cognitiveservices/account/project/costcontrol/_delete.md)
: Delete a project-owned cost control synchronously. An existing legacy attachment must be removed before its control can be deleted.

- [head](/Commands/cognitiveservices/account/project/costcontrol/_head.md)
: Checks whether a project-owned cost control exists without returning its body.

- [list](/Commands/cognitiveservices/account/project/costcontrol/_list.md)
: List project-owned cost controls using the budget representation. An unrepresentable legacy entry causes the complete list request to fail.

- [show](/Commands/cognitiveservices/account/project/costcontrol/_show.md)
: Get a project-owned cost control and its representation entity tag. Successful reads return 200 with the resource body.

- [update](/Commands/cognitiveservices/account/project/costcontrol/_update.md)
: Update a project-owned budget synchronously.
