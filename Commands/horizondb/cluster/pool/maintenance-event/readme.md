# [Group] _horizondb cluster pool maintenance-event_

Manage Maintenance Event

## Commands

- [list](/Commands/horizondb/cluster/pool/maintenance-event/_list.md)
: List maintenance events for a HorizonDB pool. Use the OData $filter query parameter to filter by properties/status with the eq and or operators. For example, properties/status eq 'Planned' or properties/status eq 'InProgress' returns upcoming events.

- [show](/Commands/horizondb/cluster/pool/maintenance-event/_show.md)
: Get information about a maintenance event for a HorizonDB pool.
