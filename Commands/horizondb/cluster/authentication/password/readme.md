# [Group] _horizondb cluster authentication password_

Manage password authentication settings for a HorizonDB cluster.

## Commands

- [create](/Commands/horizondb/cluster/authentication/password/_create.md)
: Create or replace password authentication settings for a HorizonDB cluster.

- [show](/Commands/horizondb/cluster/authentication/password/_show.md)
: Show password authentication settings for a HorizonDB cluster.

- [update](/Commands/horizondb/cluster/authentication/password/_update.md)
: Update password authentication settings for a HorizonDB cluster.
