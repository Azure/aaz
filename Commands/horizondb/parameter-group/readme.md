# [Group] _horizondb parameter-group_

Manage a HorizonDB Parameter Group

## Subgroups

- [connection](/Commands/horizondb/parameter-group/connection/readme.md)
: Manage HorizonDB Parameter Group Connections

## Commands

- [create](/Commands/horizondb/parameter-group/_create.md)
: Create a new HorizonDB parameter group.

- [delete](/Commands/horizondb/parameter-group/_delete.md)
: Delete a HorizonDB parameter group. Deletion fails with a conflict when the parameter group is associated with one or more pools.

- [list](/Commands/horizondb/parameter-group/_list.md)
: List HorizonDB parameter groups.

- [show](/Commands/horizondb/parameter-group/_show.md)
: Get information about a HorizonDB parameter group.

- [update](/Commands/horizondb/parameter-group/_update.md)
: Update an existing HorizonDB parameter group.
