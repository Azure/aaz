# [Group] _horizondb parameter-group default_

Manage default HorizonDB parameter groups.

: List default HorizonDB parameter groups in a region.

- [show](/Commands/horizondb/parameter-group/default/_show.md)
: Get a default HorizonDB parameter group in a region.
