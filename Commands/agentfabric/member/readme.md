# [Group] _agentfabric member_

Manage Agent Fabric members.

Members are children of an Agent Fabric and require the parent Fabric name. Member workloads can describe ACI, AKS, or Agent Fabric sandbox resources.

## Commands

- [create](/Commands/agentfabric/member/_create.md)
: Create an ACI, AKS, or sandbox member under an Agent Fabric.

- [delete](/Commands/agentfabric/member/_delete.md)
: Delete an Agent Fabric member.

- [list](/Commands/agentfabric/member/_list.md)
: List members of an Agent Fabric.

- [show](/Commands/agentfabric/member/_show.md)
: Show an Agent Fabric member.

- [update](/Commands/agentfabric/member/_update.md)
: Update an Agent Fabric member's tags or FQDN.
