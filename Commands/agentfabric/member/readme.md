# [Group] _agentfabric member_

Manage members that are children of an Agent Fabric. The parent Fabric name is required.

## Commands

- [create](/Commands/agentfabric/member/_create.md)
: Create a member resource as a child of an Agent Fabric. The parent Fabric name is required.

- [delete](/Commands/agentfabric/member/_delete.md)
: Delete a member resource that is a child of an Agent Fabric. The parent Fabric name is required.

- [list](/Commands/agentfabric/member/_list.md)
: List member resources that are children of an Agent Fabric. The parent Fabric name is required.

- [show](/Commands/agentfabric/member/_show.md)
: Show a member resource that is a child of an Agent Fabric. The parent Fabric name is required.

- [update](/Commands/agentfabric/member/_update.md)
: Update a member resource that is a child of an Agent Fabric. The parent Fabric name is required.
