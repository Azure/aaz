# [Group] _agentfabric egress-trust-bundle_

Read Agent Fabric egress trust bundles.

Read the service-managed egress TLS-inspection trust bundle for an Agent Fabric. The singleton bundle is read-only and should be cached for its advertised validity period.

## Commands

- [list](/Commands/agentfabric/egress-trust-bundle/_list.md)
: List egress trust bundles for an Agent Fabric.

- [show](/Commands/agentfabric/egress-trust-bundle/_show.md)
: Show the default egress trust bundle for an Agent Fabric.
