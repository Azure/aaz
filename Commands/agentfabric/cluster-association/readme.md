# [Group] _agentfabric cluster-association_

Manage Cluster Association resources that are children of an Agent Fabric. The parent Fabric name is required.

## Commands

- [create](/Commands/agentfabric/cluster-association/_create.md)
: Create a Cluster Association resource as a child of an Agent Fabric. The parent Fabric name is required.

- [delete](/Commands/agentfabric/cluster-association/_delete.md)
: Delete a Cluster Association resource that is a child of an Agent Fabric. The parent Fabric name is required.

- [list](/Commands/agentfabric/cluster-association/_list.md)
: List Cluster Association resources that are children of an Agent Fabric. The parent Fabric name is required.

- [show](/Commands/agentfabric/cluster-association/_show.md)
: Show a Cluster Association resource that is a child of an Agent Fabric. The parent Fabric name is required.

- [update](/Commands/agentfabric/cluster-association/_update.md)
: Update a Cluster Association resource that is a child of an Agent Fabric. The parent Fabric name is required.
