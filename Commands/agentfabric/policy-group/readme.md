# [Group] _agentfabric policy-group_

Manage independent Agent Fabric Policy Groups.

Policy Groups are independent resource-group-scoped Microsoft.NetworkSecurity peer resources and are not children of an Agent Fabric.

## Commands

- [create](/Commands/agentfabric/policy-group/_create.md)
: Create an independent Microsoft.NetworkSecurity Policy Group.

- [delete](/Commands/agentfabric/policy-group/_delete.md)
: Delete an independent Policy Group.

- [list](/Commands/agentfabric/policy-group/_list.md)
: List independent Policy Groups.

- [show](/Commands/agentfabric/policy-group/_show.md)
: Show an independent Policy Group.

- [update](/Commands/agentfabric/policy-group/_update.md)
: Update an independent Policy Group's tags.
