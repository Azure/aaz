# [Group] _network asg address-prefix-set_

Manage address prefix sets in an application security group.

## Commands

- [create](/Commands/network/asg/address-prefix-set/_create.md)
: Create an address prefix set.

- [delete](/Commands/network/asg/address-prefix-set/_delete.md)
: Delete the specified address prefix set.

- [list](/Commands/network/asg/address-prefix-set/_list.md)
: List all address prefix sets in an application security group.

- [show](/Commands/network/asg/address-prefix-set/_show.md)
: Get the specified address prefix set.

- [update](/Commands/network/asg/address-prefix-set/_update.md)
: Update an address prefix set.
