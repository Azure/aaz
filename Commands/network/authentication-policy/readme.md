# [Group] _network authentication-policy_

Manage authentication policies for identity integration of Application Gateway.

## Subgroups

- [identity](/Commands/network/authentication-policy/identity/readme.md)
: Manage managed identities of an authentication policy.

## Commands

- [create](/Commands/network/authentication-policy/_create.md)
: Create an authentication policy with the specified name within a resource group.

- [delete](/Commands/network/authentication-policy/_delete.md)
: Delete the specified authentication policy.

- [list](/Commands/network/authentication-policy/_list.md)
: List all the authentication policies in a subscription.

- [show](/Commands/network/authentication-policy/_show.md)
: Get the authentication policy with specified name within a resource group.

- [update](/Commands/network/authentication-policy/_update.md)
: Update an authentication policy with the specified name within a resource group.
