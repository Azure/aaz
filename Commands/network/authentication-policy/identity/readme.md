# [Group] _network authentication-policy identity_

Manage managed identities of an authentication policy.

## Commands

- [assign](/Commands/network/authentication-policy/identity/_assign.md)
: Assign user-assigned managed identities.

- [remove](/Commands/network/authentication-policy/identity/_remove.md)
: Remove user-assigned managed identities.

- [show](/Commands/network/authentication-policy/identity/_show.md)
: Show the details of managed identities.
