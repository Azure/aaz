# [Group] _network virtual-appliance migration_

Manage Network Virtual Appliance migrations.

## Commands

- [abort](/Commands/network/virtual-appliance/migration/_abort.md)
: Abort an in-progress Network Virtual Appliance migration.

- [commit](/Commands/network/virtual-appliance/migration/_commit.md)
: Commit the migration of a Network Virtual Appliance.

- [execute](/Commands/network/virtual-appliance/migration/_execute.md)
: Execute a prepared Network Virtual Appliance migration.

- [prepare](/Commands/network/virtual-appliance/migration/_prepare.md)
: Prepare a Network Virtual Appliance migration.
